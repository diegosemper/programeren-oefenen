Python Midterm Oefenen

Spiekbrief van alle 20 opdrachten en een oefentoets die elke ronde 20 nieuwe vragen verzint, één per opdracht. Eerst even de samenvatting lezen, dan de toets maken. Pak er een papiertje bij.

SamenvattingOefentoets

Jouw vaste routine bij elke vraag

  1. Schrijf de beginwaarden op (x = ..., y = ...).
  2. Loop regel voor regel van boven naar beneden. Schrijf elke verandering op.
  3. Bij een if: schrijf "waar" of "niet waar" erbij.
  4. Pas aan het eind: zoek je antwoord tussen de opties.

Al je fouten tot nu toe kwamen door een overgeslagen stap, niet doordat je de stof niet snapte.

Samenvatting

1. Variabelen: een doosje met een waarde

  • x = 5 stopt 5 in het doosje x. Python leest van boven naar beneden.
  • Een variabele onthoudt een waarde, geen formule. Na b = a * 2 verandert b niet meer als a verandert.
  • Rekenvolgorde: eerst * en /, dan + en -.
  • / geeft altijd een kommagetal: 4 / 4 = 1.0. // geeft een heel getal: 4 // 4 = 1.
  • Kommagetallen zijn niet altijd precies: 0.3 * 9 = 2.6999999999999997.

2. if / elif / else: één wegwijzer, één route

if x > 2:        # als ...
    ...
elif x < 2:      # anders, als ...
    ...
else:            # in alle andere gevallen
    ...
  • Python kiest precies één route per wegwijzer. Daarna wordt de rest overgeslagen.
  • Ingesprongen code (de spaties) hoort bij de regel erboven met de :.
  • == is een vraag ("is gelijk?"), = stopt iets in een doosje.
  • <= kleiner of gelijk, >= groter of gelijk. or: één van de twee moet waar zijn. and: allebei.

Valkuil: elke nieuwe if start een nieuwe wegwijzer en wordt altijd opnieuw gecheckt. elif/else horen bij de if direct erboven.

3. Tekst vergelijken

  • Tekst tussen " " heet een string. print(...) zet iets op het scherm.
  • < bij tekst = "komt eerder in het alfabet".
  • Python vergelijkt letter voor letter tot er een verschil is: "Sam" < "Sara" is waar (m vóór r).
  • Is één woord eerder op? Dan komt het kortere eerst: "E" < "Emily".

Valkuil: hoofdletters komen vóór kleine letters. "Z" < "a" is waar.

4. Indexing: één letter pakken

letterPython
van voren012345
van achteren-6-5-4-3-2-1
  • Van voren tellen begint bij 0. Van achteren begint bij -1 (er is geen -0).
  • Laatste index = lengte min 1. Bij een woord van 6 letters geeft woord[6] een foutmelding.

5. Slicing: een stuk pakken met [start:stop:stap]

  • Start doet mee, stop doet niet mee. "Tot, niet tot en met." "Python"[1:4] = yth.
  • Weggelaten start = vanaf het begin, weggelaten stop = tot het eind.
  • Stap 2 = elke tweede letter. Negatieve stap = achteruit lopen. woord[::-1] = achterstevoren.
  • Werkwijze: schrijf de indexen uit (bv. 0, 3, 6), zoek daarna pas de letters.

Valkuil: loopt de stap de verkeerde kant op (bv. [-1:1:2]), dan krijg je een lege string.

6. Functies: een recept

def dubbel(getal):      # recept opschrijven (nog niet uitvoeren!)
    return getal * 2    # resultaat teruggeven

print(dubbel(7) + 1)    # dubbel(7) wordt 14, dan 14 + 1 = 15
  • def schrijft het recept alleen op. Pas bij het aanroepen (dubbel(7)) wordt het uitgevoerd.
  • Een aanroep wordt vervangen door wat hij teruggeeft. Alleen wat tussen de haakjes staat gaat de functie in.
  • return stopt de functie meteen.
  • Komt een functie nooit bij een return? Dan geeft hij None terug (= niks).

Valkuil: een functie aanroepen vóór de def geeft een fout. Maar binnen een andere functie (zoals main) mag het wel, zolang die pas na alle defs echt uitgevoerd wordt.

  • Invul-trucje: zie je een naam met haakjes? Zoek de def, vul de getallen in, reken de return uit.
  • De x in def function2(x) is alleen de naam van het vakje. function2(y) stopt de waarde van y in dat vakje. Kijk naar de getallen, niet naar de letters.
  • Een return die even ver staat als de if hoort er niet bij en stopt de functie altijd. Alles eronder is dode code.

7. while: zolang ... blijf herhalen

while y >= 0:      # zolang y >= 0 is:
    print("hoi")      #   doe dit
    y = y - 1         #   en dit, dan terug naar de check
  • Volgorde per ronde: check → alle ingesprongen regels → terug naar de check. Stoppen gebeurt alleen bij de check.
  • Maak een tabel en check de laatste ronde extra goed: >= doet bij gelijk nog een ronde, > niet.
  • De waarde kan over de grens heen schieten: x = x * 2 met while x < 100 eindigt op 128.
  • "Hoe vaak" = tellen. "Wat drukt het af" = kijk wat er in de print staat. Een print na de lus gebeurt één keer.

Valkuil: na een regel met : moet minstens één ingesprongen regel komen, anders werkt het programma niet. En komt x terug op een waarde die je al had? Dan is het een oneindige lus en wordt er nooit iets geprint.

8. for en range: voor elk getal in het rijtje

  • range(0, 5) = 0, 1, 2, 3, 4. Start doet mee, stop niet (net als slicing).
  • for i in range(0, 5): draait precies 5 keer, i is steeds het volgende getal.
  • Schrijf eerst het rijtje op en streep elke ronde af. De foute antwoorden zijn vaak de tussenstanden.

9. Rekenen: %, += en delen door 0

  • % = de rest na delen. 7 % 2 = 1.
  • x % 2 == 0 → "x is even". getal % x == 0 → "x past precies in getal".
  • n += 1 is kort voor n = n + 1. Ook -= en *=.
  • Kommagetallen schrijf je met een punt: 4.0. Na een / blijft x een kommagetal, ook na + 1.

Valkuil: delen door 0 geeft altijd een fout, ook met %. Let dus op range(0, ...) als er door x gedeeld wordt.

10. Lijsten en not

  • lis = [] is een lege lijst. lis = lis + [x] plakt x achteraan.
  • my_list[ix] werkt als indexing bij tekst: ix is de plek, my_list[ix] het getal op die plek.
  • not draait waar en niet waar om: not x % 2 == 0 → "x is oneven".
  • Lees het in één zin: "ga elk getal langs, oneven → keer 2, even → laten zo".
